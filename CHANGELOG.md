# Changelog

## 1.0.0 (2026-11-22)

### New

* Roll D4, D6, D8, D10, D12, D20, a coin or a custom die with 2–9999 sides.
* Results appear in place of the tapped icon for five seconds.
* Combine rolls into a set with a total and count, reroll the same set or start a new one.
* Optional vibration, keep screen on and dark theme.
* Choose from 63 languages. Fully offline, with no ads or tracking.
